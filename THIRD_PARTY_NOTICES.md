# Third-party software

This is an independent offline packaging of the Babylon.js Sandbox, not an
official Babylon.js deployment. The original Sandbox interface and engine are
provided by https://github.com/BabylonJS/Babylon.js under Apache License 2.0.
Upstream copyright and license banners are preserved in downloaded scripts.

The published site includes Babylon.js libraries, Draco, meshoptimizer, Basis
Universal/KTX2 transcoders, glTF validator, Havok, Ammo.js, Cannon.js, Oimo.js,
glslang and twgsl distributed by the Babylon.js CDN. Their original notices in
the distributed files continue to apply. Included environment maps and the
default demo model originate from https://assets.babylonjs.com/.

`upstream-snapshot.json` records the exact URL, SHA-256 and size of every asset
captured for each deployment. The offline packaging code is Apache-2.0.
